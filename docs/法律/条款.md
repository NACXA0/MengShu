## 2. 服务定义

### 2.1 盟书是什么

双边签认、密码学存证的关系记录工具：两人可共同签署关系档案，签署行为经国密算法签名并锚定至司法区块链，产生不可篡改、可独立核验的存证记录。

### 2.2 盟书不是什么（重要，请仔细阅读）

| 盟书**不是** | 说明 |
|---|---|
| 婚恋交友平台 | 不提供任何撮合、匹配、推荐功能，永远不会 |
| 征信机构 | 不出具任何信用评分、信用报告 |
| 背景调查工具 | 不主动向任何第三方提供你的信息，公示与授权完全由你决定 |
| 内容真实性担保方 | **我们证明"签署发生过、内容未被篡改"，不证明"内容真实"**——宣誓是用户对法律的承诺，不是对我们的承诺 |
| 关系质量担保方 | 双签与关系幸福之间不存在任何因果关系 |

## 4. 用户行为规范

### 4.1 关系陈述的特别责任

- 陈述功能为实名+关系存证绑定，你的身份、关系存在性、陈述内容三者哈希关联，**追责链条完整**；
- 陈述内容失实构成对他人名誉权侵害的，**全部法律责任由你自行承担**；配合司法调证是我们的法定义务；
- 每段关系仅可提交一份陈述（≤200 字），提交后 7 天内可修改，此后锁定；对方享有答辩权且双向并列展示。

### 4.2 禁止行为

| # | 禁止行为 |
|---|---|
| 1 | 伪造身份、冒用他人实名信息注册 |
| 2 | 批量注册账号（Sybil 攻击） |
| 3 | 对公开页进行爬取、逆向、自动化访问（公开页仅限链接到达，频控之外的行为视为滥用） |
| 4 | 利用授权码、扫码验证机制进行骚扰或人肉搜索 |
| 5 | 在陈述中发布侮辱、诽谤、泄露他人隐私的内容 |
| 6 | 干扰、破坏服务的正常运行（DDoS、漏洞利用等） |
| 7 | 将获取的数据用于授权范围之外的用途（针对机构用户，见 §6） |

## 5. 内容治理

- 陈述内容经 PII 过滤、敏感词初筛、抽样人工复审；
- 举报通道：任一陈述可被举报，我们 **24 小时内**处理（《民法典》第 1195-1197 条义务）；
- 处理原则：**我们删除违法内容（诽谤、隐私泄露、PII），但不删除"难听但真实合法"的陈述**——中立是产品根基，我们不做内容品味的仲裁者；
- 双向并列展示不可绕过：任何一方（包括我们）都无法单方删除对方的陈述文本。

### 6.1 准入

企业资质审核 + 签署《数据合规承诺书》+ mTLS 客户端证书 + IP 白名单。未完成准入的任何形式的接入尝试均属违约。

### 6.2 机构义务

| # | 义务 |
|---|---|
| 1 | 查询与接收数据**仅限婚恋服务核验用途** |
| 2 | **禁止缓存、导出、转售**任何获取的数据 |
| 3 | 响应携带有效期戳（valid_until）过期后不得继续使用该数据 |
| 4 | 用户撤回公示/行使删除权时，配合删除协助通知 |
| 5 | 用户拒绝授权时，不得以任何形式追问原因、不得歧视未公示用户 |

### 6.3 违约后果
