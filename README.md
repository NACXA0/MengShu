## 这是什么
两个人认真开始一段关系时，可以在这里共同签署一份"关系档案"：内容经双方各自实名确认、以国密算法签名、哈希锚定至司法区块链——**从此这段事实不可篡改、不可抵赖、可被独立核验**。
它不是婚恋平台，不是背景调查工具，不是信用评分系统。它只做一件事：
> **认真恋爱的人，希望关系是公开且可被证明的；寻找关系的人，希望了解对方的真实经历。**
盟书为这两件事提供密码学与法律层面的基础设施。
## 灵魂红线（先读这个）
本项目的所有设计决策都服从一条不可妥协的约束：
```

Vault 区数据向第三方的输出 = 0 字节。
任何商业模式、任何后续需求、任何"仅此一次"都不在此开缝。

```
这意味着：你在"保险库"里的东西，**连你自己现场授权，平台也不会把它传给任何机构**。这条红线写入了 PRD、SRS、权限矩阵与渗透测试用例，是一票否决项。

## 核心特性
**Vault（保险库）**
- 双边签认：双方各自 SM2 签名，任何一方事后篡改本地记录立即暴露
- 完整性宣誓：可被日后证伪的"档案完整"承诺，签名锚定上链
- 零存储：服务器永远只有加盐哈希，明文不出你的设备
- 和平关闭协议 / 单方注销：关系的结束方式本身也被存证
**Plaza（广场）**
- 自愿公示：Opt-in 默认关闭，字段自选（关系数以区间呈现，非精确数字）
- 一键撤下：公开页 ≤ 1 分钟下线，API ≤ 5 分钟失效
- 关系陈述：仅限双签关闭关系的双方，实名、双向并列、有答辩权
- **不收平台运营费**；全平台唯一付费项为支付宝[身份验证](https://open.alipay.com/api/detail?code=I1080300001000044085&index=1)（非「人脸核验」）
**机构 API（婚恋服务合规通道）**
- 场景 A：批量查询已公示字段（带有效期戳，撤回即失效；**不收查询运营费**）
- 场景 B：本人现场 OAuth2.0 授权 + 身份验证，摘要传输至机构系统（不传 Vault 明细；不收接口运营费）
- 白名单制 + mTLS + 合同限定用途
## 信任机制（一段话版）
关系记录的明文永远停留在双方手机本地。签署瞬间，本地计算加盐 SM3 哈希，双方各自以 SM2 私钥签名，经国家授时中心 TSA 加时间戳，以 Merkle 批量方式锚定至至信链（司法联盟链）。发生纠纷时，向法院提交本地明文 + 链上存证编号，法院后台重算哈希与链上比对——**验证一致即真实性推定成立，全程无需平台介入**。详见 [技术白皮书](docs/tech-whitepaper.md)。

## 技术栈
- **密码学**：SM2（签名）/ SM3（哈希，全部 HMAC 加盐）/ SM4（本地加密），符合 GB/T 32905-2016 等国密标准
- **链上锚定**：至信链（司法联盟链）+ 国家授时中心 TSA 时间戳，AnchorBackend 插件化可替换
- **客户端（当前）**：支付宝小程序主端 + 支付宝云开发（云函数 / 云数据库）；口令与助记词仅存本机
- **身份**：支付宝 OPENID（云函数 `getAlipayContext`）+ **身份验证**门控（[开放平台产品](https://open.alipay.com/api/detail?code=I1080300001000044085&index=1)；非「人脸核验」）；**不收平台运营费**，全平台唯一付费项为该身份验证
- **合规**：参照《个人信息保护法》《电子签名法》、GB/T 8567、ISO/IEC/IEEE 29148

## FAQ
**Q: 服务器上到底存了什么？**
A: Vault 区只有加盐哈希、签名值、DID（非明文身份）。Plaza 区只有你显式公示的字段与陈述。无任何姓名、手机号、身份证、人脸——这是 schema 级自证，源码开源可核验。
**Q: 删除"被遗忘权"如何实现？**
A: 本地 SM4 密钥 + 全部盐销毁 → 明文物理不可恢复；链上残留哈希失去字典攻击面，依《个人信息保护法》第 4 条匿名化条款视为完成删除义务。
**Q: 机构能查到我的 Vault 吗？**
A: 不能。任何 API 路径不可达 Vault 数据，此为渗透测试一票否决项。现场授权（场景 B）也只传 Plaza 级摘要。
**Q: 评价功能会不会变成看准网？**
A: 不会。区别在于：① 必须实名；② 必须有双方签认的存证关系才有资格写；③ 双向并列 + 答辩权强制展示；④ 责任链条完整（评价者身份→关系存证→内容三者哈希关联）。评价是附加功能，不是核心。
**Q: 为什么是国密而不是 SHA-256 / ECDSA？**
A: 合规要求 + 国产密码自主可控。SM 系列算法已获国际 ISO 标准化认可，且在司法存证场景有成熟判例支撑。
